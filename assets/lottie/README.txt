ALPHAZOO - LOTTIE ANIMATIONS FOLDER
====================================

This folder is OPTIONAL and can contain Lottie JSON animation files.

USAGE:
------
Lottie animations can be used for:
- Splash screen animations
- Decorative elements
- Loading indicators
- Transition effects

SUGGESTED FILES:
---------------
- splash.json - Animation for splash screen
- stars.json - Star sparkle effects
- confetti.json - Celebration effects

WHERE TO GET LOTTIE FILES:
-------------------------
- LottieFiles.com (https://lottiefiles.com)
- Create custom animations with After Effects + Bodymovin
- Commission custom animations

IMPORTANT:
----------
The app works perfectly WITHOUT Lottie files. They are purely optional enhancements.
If no Lottie files are present, the app uses native Flutter animations instead.

FILE FORMAT:
-----------
- JSON format only
- Keep file sizes small (< 100KB per file)
- Test animations before adding to ensure performance
