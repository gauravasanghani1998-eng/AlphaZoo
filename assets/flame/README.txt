ALPHAZOO - FLAME ENGINE ASSETS FOLDER
=====================================

This folder is OPTIONAL and can contain sprites/images for Flame engine animations.

USAGE:
------
Flame assets can be used for:
- Particle effects (stars, sparkles, fireflies)
- Background animations (parallax, floating objects)
- 2D sprite animations

SUGGESTED FILES:
---------------
- particle.png - Small particle sprite
- star.png - Star sprite for sparkle effects
- bubble.png - Floating bubble sprite

SPECIFICATIONS:
--------------
- PNG format with transparency
- Small size (32x32 to 128x128 pixels)
- Simple, colorful designs
- Optimized for performance

IMPORTANT:
----------
The app includes built-in Flame animations that work WITHOUT custom sprites.
These assets are purely optional enhancements.

If no Flame assets are present, the app uses:
- Programmatic particle rendering (circles, shapes)
- Default Flutter/Flame rendering

The Flame implementation is minimal and lightweight - no complex game logic required.
