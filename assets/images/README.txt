ALPHAZOO - IMAGES FOLDER
========================

This folder should contain:

1. app_logo.png - App logo (REQUIRED - provided)
2. placeholder.png - Fallback image when letter images are missing
3. a.png through z.png - Individual letter images (26 files)

INSTRUCTIONS:
-------------

To add letter images:
1. Prepare 26 images representing each letter (A through Z)
2. Name them: a.png, b.png, c.png, ... z.png (lowercase)
3. Recommended size: 500x500px or larger
4. Format: PNG with transparent background preferred
5. Ensure images are kid-friendly and colorful

EXAMPLE LETTER IMAGES:
- a.png → Apple
- b.png → Ball
- c.png → Cat
- d.png → Dolphin
... and so on

If images are missing, the app will show a placeholder icon instead.

NOTE: The app logo (app_logo.png) has been provided with this project.
You can extract individual letter images from the provided A-Z collection image,
or create/source your own images.
