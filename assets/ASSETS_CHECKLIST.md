## Quick Commands

After adding assets, run:
```bash
flutter pub get
flutter clean
flutter run
```

## Notes

- File names must be lowercase
- PNG format recommended for images
- MP3 format required for sounds
- App will work with missing assets (shows placeholders)
- Minimum required: app_logo.png for best experience
